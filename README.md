# Android Raytracer Demo

A performant raytracing implementation for Android demonstrating graphics rendering capabilities.

## Features
- Real-time ray tracing visualization
- Optimized for mobile performance
- Interactive camera controls
- Material property configuration

## Requirements
- Android Studio Giraffe | 2022.3.1+
- Android SDK 34
- Gradle 8.0+

## Installation
1. Clone repository
2. Open in Android Studio
3. Build &amp; Run with ./gradlew assembleDebug

## Building from CLI
```bash
./gradlew installDebug
```
